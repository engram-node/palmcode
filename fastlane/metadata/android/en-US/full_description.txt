palmcode is a coding-agent harness that runs entirely on your phone.

Point it at a vLLM-serving endpoint with your own API key: a hosted
gateway, or a server on your LAN or Tailscale.
Sessions, repos, files, shell execution, API keys, and history never leave
the device. There is no backend, no account, no telemetry, and no crash
reporting.

<b>Agent:</b> streaming sessions, file tools (read/write/edit/patch), bash
with a real busybox userland, ripgrep, plan/build modes, subagents, context
compaction, rules files, custom commands, and undo â€” comparable to desktop
agent harnesses.

<b>Permissions:</b> every write and command can be gated allow/ask/deny, in
the app or from a notification.

busybox/git userland is compiled from upstream releases during the build.
